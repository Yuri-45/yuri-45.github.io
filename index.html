❓ Frequently Asked Questions

Is this app free?

Yes! 3mf-viewer is completely free to download and use. It's an open-source project developed by the community.

What is a .3mf file?

A .3mf file is a 3D printing format that includes the model's geometry AND other data like colors, materials, and even print settings. It's the modern standard for 3D printing.

Can I edit the 3D models with this app?

No, 3mf-viewer is for viewing and organizing models, not editing. For editing, you'd need a program like Blender, Fusion 360, or Tinkercad.

My computer runs Windows. Will this work?

Yes. The current version works on Windows 11 and Windows 10. Just download the Windows file from the releases page.

Is my data safe?

Absolutely. The app runs locally on your computer and does not upload your models anywhere. Your files stay private.

📖 Support and Troubleshooting

Common Issues

  • App won't start: Make sure you have the latest version installed. If you have an older Windows version, check compatibility settings.
  • Model appears black: This can happen with certain color profiles. Try updating your graphics drivers.
  • Slow performance: Close other applications and make sure your laptop is not in battery saver mode.

Getting Help

If you run into any other issues, please visit the official support page and let us know what happened. Include a screenshot and a short description of the problem.
